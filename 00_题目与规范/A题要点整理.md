## 1. 背景与主线

中国可采致密油约 178.2 亿吨，占可采石油资源约 40%，主要分布在鄂尔多斯、准噶尔、四川、松辽盆地。深部致密油基质渗透率一般不高于 0.1×10⁻³ μm²（≈0.1 mD），孔喉细小、天然裂缝不发育、单井自然产能低，常规开发采收率普遍低于 10%。

现场采用**液态/超临界 CO₂ + 纳米渗吸剂复合流体**进行储层改造与吞吐开发，三个阶段：

| 阶段 | 物理过程 | 关键动作 |
|---|---|---|
| ① 高压注入 | 按配比注入 CO₂ 与纳米剂，超过破裂压力造水力裂缝 | 注入速率、注入量、配比、注入时机 |
| ② 焖井 | CO₂ 扩散进基质、溶于油与水；纳米剂改变界面张力与润湿性；压力、有效应力、损伤状态重分布 | **焖井时间 t_s** |
| ③ 开井生产 | 采出原油与混合流体 | 生产时长 360 d |

**核心矛盾**：焖井时间是连接"改造效果"与"经济可行性"的关键变量。
- 太短 → CO₂ 未深入基质、纳米剂未充分作用，改造范围有限；
- 太长 → 作业与资金占用成本上升、产能延迟，NPV 可能下降。

**注入时机 τ_inj**：压裂完成后等待 τ_inj 天才开始注入；τ_inj = 0 表示压裂结束立即注入。

## 2. 四个问题：要求与交付物

### P1 三场耦合方程（机理建模）

建立**渗流场—应力场—损伤场**相互作用的耦合方程，至少包含：

1. 流体渗流连续性方程
2. 岩石力学本构关系
3. Biot 有效应力耦合关系
4. 损伤演化方程

必须交代：
- 物理假设
- 初始条件、边界条件
- 各方程的物理意义
- **区分注入、焖井、生产三个阶段的边界条件**

> 交付：一套自洽、可求解的耦合方程组 + 定解条件。

### P2 无量纲化与量纲分析

1. 对 P1 的耦合方程无量纲化，得到**无量纲控制参数群**，说明每个参数的物理意义；
2. 参照附录 A，给出各参数合理取值的**量级**；
3. 用量纲分析导出**焖井时间—改造影响半径的近似解析关系**；
4. 分析**哪些无量纲参数显著改变**"焖井时间 → 改造范围"这一关系。

> 交付：无量纲群表 + R(t_s) 近似解析式 + 敏感性判断。

### P3 多目标优化

- **目标**：提高储层产能 + 降低总作业成本（双目标）
- **设计变量**：C_n、q_inj、V_inj、f_CO2、t_s、τ_inj（题目表 A.3 标注 "design variable"）
- **约束**：
  - 设备能力（注入速率、日产液上限等）
  - 纳米材料用量上限 **30 t/井次**（超过即判不可行）
  - 地层承压上限 p_max = min(0.95 p_f, 60 MPa)
  - 注入 + 焖井总时长 ≤ 90 d
- **情景**：以 Case0 为基准，选三个代表情景
  - Case1 低渗高应力
  - Case2 中渗低应力
  - Case3 高渗且天然裂缝发育
- **方法**：选合适的智能优化算法，通过仿真或**代理模型**求 Pareto 最优解集；说明算法选择理由
- **交付**：每情景 2–3 个折中方案
- **鲁棒性**：对渗透率、地应力等关键参数施加 **±15% 随机扰动**，从 Pareto 集中筛选抗扰动方案，给出工程建议

### P4 数据驱动 + 经济评价 + 敏感性

1. 用**附件 C** 建产能预测模型，合理划分训练/测试集，采取措施防止过拟合；
2. 用**附录 B** 经济参数计算 NPV，绘制 **NPV 随焖井时间变化曲线**，确定三个情景的**最优焖井时间**；
3. 对比**数据驱动模型**与**机理模型**结果，出现差异时从**模型假设、数值误差、数据噪声**三方面分析原因；
4. 构建储层改造效果**综合评价指标体系**；
5. 对关键地质与工程参数做**全局敏感性分析**，找出对**最优焖井时间**影响最大的参数。

> 题目明示：P2、P3、P4 必须与 P1 保持一致。

## 3. 关键定义（题目补充说明）

### 改造半径 / 刺激半径
定义为**从裂缝面起算的法向最远距离**，在该处指定物理量达到给定阈值。可选物理量与推荐阈值：

| 物理量 | 阈值 |
|---|---|
| 孔隙压力扰动 Δp | Δp/p₀ = 5% |
| CO₂ 质量分数 | 0.01 |
| 纳米颗粒浓度 | 0.01 wt% |
| 损伤变量 d | 0.10 |

**未特别说明时，默认指压力扰动达到 5% p₀ 的法向距离。**

### 三场的严格定义（统一约定）
- **渗流场**未知量：孔隙压力、相饱和度、组分浓度
- **应力场**未知量：位移、应变、有效应力
- **损伤场**未知量：标量损伤变量 d，以及由 d 驱动的孔隙度、渗透率演化

> 孔隙压力既是渗流场未知量，又通过 Biot 有效应力进入应力场，是两场的**耦合变量**，不再单列为独立的"孔隙压力场"。背景中"渗流场—地应力场—孔隙压力场"的表述按此理解。

## 4. 八条统一假设（可放宽/替换，但须说明理由并保持全文一致）

1. 储层为等温、各向同性连续介质，基质用**单孔介质**描述；水力裂缝是嵌入基质的高导流平面区域；Case3 可叠加天然裂缝。
2. 储层条件下 CO₂ 为**超临界态**（T_c = 304.13 K，p_c = 7.38 MPa）。CO₂ 密度与黏度随压力、温度变化，用 **Peng–Robinson 方程**或附录 A 物性表描述；忽略相变潜热。
3. CO₂ 在原油与地层水中的溶解按**亨利定律瞬时平衡**；溶解引起原油膨胀与降黏。**是否单独建自由 CO₂ 相自定**——若忽略，须说明适用条件，并与考虑自由相的情形做对比。
4. 纳米颗粒**仅在水相中输运**，考虑对流、分子扩散、可逆吸附；通过降低油水界面张力、改变接触角，影响毛管压力与相对渗透率。
5. 岩石为各向同性**孔隙弹性体**，采用小变形、准静态假设；损伤用标量 d 描述；损伤后杨氏模量、孔隙度、渗透率按给定关系折减。
6. 流动服从**达西定律**；相渗与毛管压力是饱和度的函数；应力敏感性通过孔隙度、基质渗透率、缝宽、缝渗随有效应力（或孔压）变化体现。
7. 顶底盖层不渗透，外边界为定压/定应力边界；忽略重力、温度场、化学反应、盐析、沥青质析出、润湿滞后；**不允许反注**。
8. 经济评价严格按附录 B；所有注入量、产量、物料消耗按 **25 MPa、300 K 参考状态**计量；不计税费、残值、沉没成本。

## 5. 经济模型（附录 B，P3/P4 必须严格采用）

### 5.1 物料与用量

$$V_{\mathrm{CO_2}} = f_{\mathrm{CO_2}} V_{\mathrm{inj}}, \qquad V_{\mathrm{aq}} = (1-f_{\mathrm{CO_2}})\,V_{\mathrm{inj}}$$

$$m_{\mathrm{CO_2}} = \frac{\rho_{\mathrm{CO_2,ref}} V_{\mathrm{CO_2}}}{1000}, \qquad m_{\mathrm{nano}} = \frac{(C_n/100)\,\rho_{\mathrm{aq}} V_{\mathrm{aq}}}{1000}$$

其中 ρ_CO2,ref = 850 kg/m³，ρ_aq = 1000 kg/m³，C_n 以 wt% 代入（单位：t）。

成本：C_nano = c_nano·m_nano，C_CO2 = c_CO2·m_CO2。

**纳米材料上限 30 t/井次**，超过即不可行。用量按注入的纳米剂水溶液体积 V_aq 计，不按改造体积折算；若改用其他配液约定，须给出 V_aq 与改造体积的换算关系并全文一致。

### 5.2 总成本、现金流、NPV

$$C_{\mathrm{total}} = C_{\mathrm{frac}} + c_{\mathrm{inj}}t_{\mathrm{inj}} + c_{\mathrm{soak}}t_s + C_{\mathrm{nano}} + C_{\mathrm{CO_2}} + c_{\mathrm{prod}}Q_o + c_{\mathrm{water}}Q_w$$

其中 t_inj = V_inj / q_inj；Q_o、Q_w 为 360 d 生产期累计产油、产水量。

逐日净现金流：

$$CF(t) = P_{\mathrm{oil}}^* Q_o - c_{\mathrm{prod}}Q_o - c_{\mathrm{water}}Q_w - c_{\mathrm{inj}}I_{\mathrm{inj}} - c_{\mathrm{soak}}I_{\mathrm{soak}} - c_{\mathrm{nano}}m_{\mathrm{nano,day}} - c_{\mathrm{CO_2}}m_{\mathrm{CO_2,day}}$$

$$NPV = -C_{\mathrm{frac}} + \sum_{t=1}^{T}\frac{CF(t)}{(1+r)^{t/365}}$$

- 候选方案：T = t_inj + t_s + 360 d
- 基准方案 B1（仅压裂、不注复合流体）：T = 360 d
- **增量净现值** ΔNPV = NPV − NPV_B1
- 折现基准为第 0 天，按日终折现
- 生产阶段不计日作业费，只计可变生产成本与采出水处理费；焖井阶段计日费；注入阶段按**实际注入天数**计费

### 5.3 统一换算（万元、吨、立方米、天）

| 量 | 值 |
|---|---|
| c_nano | 20×10⁴ CNY/t |
| c_CO2 | 0.03×10⁴ CNY/t |
| c_prod | 0.035×10⁴ CNY/m³ |
| c_water | 0.0025×10⁴ CNY/m³ |
| P_oil* | 0.3396×10⁴ CNY/m³ |

> 换算示例（原文）：V_inj = 3000 m³、f_CO2 = 0.5、C_n = 1.0 wt% → V_aq = 1500 m³，m_nano = 15 t，材料费 300×10⁴ CNY；m_CO2 = 1275 t，CO₂ 费 38.25×10⁴ CNY；注入 10 d、焖井 30 d → 注入费 300×10⁴ CNY、焖井费 90×10⁴ CNY，加压裂费 120×10⁴ CNY，小计 848.25×10⁴ CNY（不含生产费用）。

## 6. 附件 C 数据说明

- 文件：`01_数据/附件C_Synthetic_Production_Data.xlsx`
- 规模：**38,880 条** = 3 情景 × 3 纳米浓度 × 12 焖井时间 × 360 生产日
- 生成方式：由**参考机理模型**生成，日产油含 **±5% 高斯噪声**，并截断为非负；**不是现场观测，也不是"标准答案"**

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| Case_ID | 文本 | — | Case1 低渗高应力 / Case2 中渗低应力 / Case3 高渗复杂裂缝 |
| Nano_Concentration_wt% | 数值 | wt% | 0.5 / 1.0 / 1.5 |
| Soak_Time_Days | 整数 | d | 5–60，步长 5，共 12 档 |
| Production_Day | 整数 | d | 1–360 |
| BHP_MPa | 数值 | MPa | 生产阶段井底流压模拟值，初期可能短暂超过原始地层压力 |
| Oil_Rate_m3_d | 数值 | m³/d | 日产油，含 ±5% 噪声 |
| Cum_Oil_m3 | 数值 | m³ | 累计产油（含截至当日），继承噪声 |

### 使用规则（硬性）

1. 按"**情景 × 浓度 × 焖井时间**"整组划分训练/验证/测试，**禁止**随机拆分同一组内相邻生产日。
2. 测试集必须**至少包含一个未参与训练的焖井时间档**，以检验外推能力。
3. **不得**由 Cum_Oil_m3 反推日产油再加噪（会重复计噪）；禁止由 Cum_Oil 反算产量。
4. 附件 C 只覆盖 C_n 与 t_s 两个操作维度；其余变量对产能的影响须由机理模型或明确假设给出。
5. 允许平滑、去噪、分组聚合，但须说明方法，并保留与原始数据的对比。

### 一致性说明

BHP 是生产阶段模拟值，初期可能短暂超过原始地层压力（反映注入后近井带压力未完全消散）。**BHP 与产量不构成参赛者模型的边界条件，也不要求逐条复现**。应关注**趋势、量级、相对排序**，而非逐点拟合。
