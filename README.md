## 提交规范（硬性）

- 论文**英文**撰写，A4，正文 12 pt Times New Roman，**不超过 25 页**（摘要页、目录页、附录页不计）
- **摘要必须是第 1 页**，不能拆成两个文件
- 论文正文与附录**不得出现学校、姓名等身份信息**
- 命名格式：
  - 论文 `A + 队伍号 + .pdf`，例：`ASWBMCM2600001.pdf`
  - 承诺书 `A + 队伍号 + cns`，例：`ASWBMCM2600001cns.pdf`
  - 支撑材料 `A + 队伍号 + fj`，例：`ASWBMCM2600001fj.zip`
- 论文 PDF 单文件 ≤ 20 MB
- 提交入口：https://www.mojinghub.com/competitions/swbmcm/2026（备用邮箱 mcm@nmmcm.org.cn）

## 协作约定

仓库为**私有**，比赛期间不公开，避免他队看到进度与思路。

- `main` 分支保持可运行、可编译
- 各自在分支上工作，命名 `feat/p1-equations`、`feat/p3-nsga2`、`fix/data-split` 等
- 合并前先 `git pull --rebase origin main`，再开 PR 或直接合并
- 二进制文件（xlsx、pdf）避免反复覆盖，改数据前先说明
- 每次提交只做一件事，提交信息写清对应问题号（如 `P2: 无量纲群推导`）
- **不要**把 API key、账号密码写进仓库

数据与代码的对应关系：

| 文件 | 用途 |
|---|---|
| `01_数据/附件C_Synthetic_Production_Data.xlsx` | P4 产能预测 |
| `01_数据/A题参数表_整理.xlsx` | P1–P4 参数取值 |
| `02_代码/extract_parameters.py` | 从原题 PDF 重建参数表 |
